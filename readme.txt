Project Name
Order Analytics System

GitHub repo name:
java-streams-order-analytics

This is simple, practical, and interview-friendly.

What this project is:-
A small Java app that analyzes:
-> customers
-> orders
-> products

You will use Java Streams to answer business questions like:

-> total revenue
-> top customers
-> most sold product
-> orders by city
-> average order value
-> products sold more than 5 times
-> distinct categories
-> grouping and partitioning

This project is good because it gives you nested collections, which is where Streams become powerful.

Classes:-
-> Product
-> OrderItem
-> Order
-> SampleData
-> Main Class
